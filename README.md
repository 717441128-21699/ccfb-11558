# jsonrel — 嵌套 JSON 自动拍平成关系表

从各合作方开放接口拉回来的层层嵌套 JSON，自动拍平成 SQLite 里的多张关联表，
分析师直接查表；同时支持从关系表**无损反向还原**原始 JSON。

## 快速开始

```bash
# 1) 生成 10 种结构 × 5000 条演示样本（samples/*.jsonl）
py -I scripts/gen_samples.py

# 2) 端到端验收：推断 → 设计 → 加载 → 反向还原 → 逐条比对 50000 条
py -I scripts/verify_roundtrip.py

# 3) 启动网页（默认库 project.db；想用验收库就设环境变量）
py webapp.py                      # http://127.0.0.1:5000
# 或直接浏览已加载好的 5 万条数据：
$env:JSONREL_DB="verify.db"; py webapp.py
```

网页包含五个功能页：**样本上传 → 结构推断 → 表设计 → 映射规则 → 加载记录**，
另有"还原校验"页做全量比对和单条原文/还原对照。

## 七项需求对应实现

| # | 需求 | 实现 |
|---|------|------|
| 1 | 扫样本推结构，记录缺失/类型比例 | `jsonrel/infer.py`：按文档级统计每个路径的出现次数、类型分布、数组元素类型分布；网页"结构推断"页展示出现率 |
| 2 | 对象拍平成列，数组拆子表 | `jsonrel/flatten.py`：子表带 `__parent_id`（父表主键）和 `__idx`（数组下标） |
| 3 | 字段类型不稳定给建议 | `jsonrel/design.py: suggest_for`：对象/数组/字符串混合 → 建议 JSON 列；标量混杂 → 建议 JSON 列；网页"结构推断"页展示建议 |
| 4 | 无自然主键自动生成稳定键 | `jsonrel/common.py: doc_key`：有自然键（自动推荐唯一 id 字段）用自然键哈希，否则用整文档规范化哈希；同一数据重复加载键不变（`INSERT OR REPLACE` 幂等） |
| 5 | 新字段自动加列，旧数据补空 | 加载期 `ensure_path` 自动登记新路径，`ALTER TABLE ADD COLUMN`，旧行自然为 NULL；记录在加载记录里 |
| 6 | 用户改规则：子表↔JSON列、层级合并 | 网页"映射规则"页：数组可改 JSON 列，对象可"展开为列(合并层级)"或存 JSON 列；保存后自动重建并重载 |
| 7 | 关系表反向拼回原始 JSON | `jsonrel/reconstruct.py`：每行 `__present` 记录出现性（区分缺失与 null、保留空对象/空数组），还原后与原文语义一致 |

## 类型漂移的自动处理

加载时实际值与既有规则不兼容（如 `amount` 前 4000 条是数字、之后变成字符串，
`aircraft` 由对象退化为字符串）时，规则自动升级为 JSON 列，已入库数据即时迁移
（`jsonrel/migrate.py`：标量列值改写为 JSON 文本并重建列类型；子表行重新拼成数组写回父表），
全程不丢数据，还原依然逐条一致。

## 目录结构

```
jsonrel/            核心包（推断/设计/拍平/存储/迁移/还原/高层API）
webapp.py           Flask 网页台
scripts/gen_samples.py       10 种结构差异大的样本生成器（各 5000 条）
scripts/verify_roundtrip.py  端到端验收（50000 条全量比对 + 幂等性检查）
scripts/smoke_web.py         网页冒烟测试（含改映射规则）
samples/            生成的演示样本
```

## 验收结果

- 10 个数据源 × 5000 条，每源仅用前 500 条做结构推断，其余字段靠加载期自动演进
- 全量加载后反向还原，与原始文档逐条比对：**50000/50000 一致**
- 重复加载一遍：键稳定、行数不变（幂等），再次比对仍 50000/50000
- 过程中自动加列 118 个、类型漂移自动升级 4 次，全部无损
